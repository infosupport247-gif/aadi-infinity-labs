# AADi Infinity Labs
Local website prototype. Requires Python 3; no external dependencies. On Mac run `bash START.command` from this folder. Open http://localhost:8769 and /admin. Choose a strong admin password. SQLite stores edits in site.db. Restarting invalidates login sessions. Back up site.db. Image URLs are managed in admin; screenshots use one URL per line. Legal text is intentionally blank pending review. No live App Store links are assumed. This local server is not production-ready: deploy using a production web server, HTTPS, secure cookies, persistent session storage, login throttling, backups and security review. Contact and deletion pages provide configurable information, not a submission workflow. No analytics, newsletter, AI support or multilingual translation is implemented.
